DAY 4 - QUESTION 11: Data Normalization Methods
========================================================================
Given Strike-rates: [100, 70, 60, 90, 90]
Stats:
- Min = 60, Max = 100
- Mean (mu) = (100 + 70 + 60 + 90 + 90) / 5 = 410 / 5 = 82.0
- Sample Standard Deviation (s) ≈ 16.43 (Population sigma ≈ 14.70)
- Mean Absolute Deviation (MAD) = (|100-82| + |70-82| + |60-82| + |90-82| + |90-82|) / 5
                               = (18 + 12 + 22 + 8 + 8) / 5 = 68 / 5 = 13.6

1. (a) Min-Max Normalization to [0, 1]:
   Formula: v' = (v - Min) / (Max - Min) = (v - 60) / 40
   - 100 -> (100 - 60) / 40 = 1.00
   - 70  -> (70 - 60) / 40  = 0.25
   - 60  -> (60 - 60) / 40  = 0.00
   - 90  -> (90 - 60) / 40  = 0.75
   - 90  -> (90 - 60) / 40  = 0.75
   Normalized: [1.00, 0.25, 0.00, 0.75, 0.75]

2. (b) Z-Score Normalization (using s = 16.43):
   Formula: v' = (v - mu) / s = (v - 82) / 16.43
   - 100 -> (100 - 82) / 16.43 = +1.095
   - 70  -> (70 - 82) / 16.43  = -0.730
   - 60  -> (60 - 82) / 16.43  = -1.339
   - 90  -> (90 - 82) / 16.43  = +0.487
   - 90  -> (90 - 82) / 16.43  = +0.487
   Normalized: [1.10, -0.73, -1.34, 0.49, 0.49]

3. (c) Z-Score Normalization using MAD (MAD = 13.6):
   Formula: v' = (v - mu) / MAD = (v - 82) / 13.6
   - 100 -> 18 / 13.6 = +1.324
   - 70  -> -12 / 13.6 = -0.882
   - 60  -> -22 / 13.6 = -1.618
   - 90  -> 8 / 13.6   = +0.588
   - 90  -> 8 / 13.6   = +0.588
   Normalized: [1.32, -0.88, -1.62, 0.59, 0.59]

4. (d) Normalization by Decimal Scaling:
   Formula: v' = v / 10^j where max(|v'|) < 1 -> j = 3 (since Max = 100, 100/1000 = 0.1 < 1)
   - 100 -> 0.100
   - 70  -> 0.070
   - 60  -> 0.060
   - 90  -> 0.090
   - 90  -> 0.090
   Normalized: [0.100, 0.070, 0.060, 0.090, 0.090]
